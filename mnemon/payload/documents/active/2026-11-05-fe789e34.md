# 灰誓：战斗特效与手牌呈现美术打磨（2026-11-05）

承接 11-04 的 UI 同版改造，本轮只做"表现层"：手牌插画画窗、角色格舞台底光、意图条图标、命中/受击特效。不改规则与数值。

## 主要改动

- **手牌画窗**：原先卡图按常数高度增长，1024×576 的插画被裁成中段（剑只剩护手）。改为先用 `TextParagraph` 按真实换行量出说明文字高度，再倒推画窗高度 → 短文案卡在宽 156 时约 72px 画窗，名字绶带压在画面底部；长文案卡自动把高度让给文字。卡按钮仍走 `ui` 层 `_card(parent, instance, callback, dimensions=Vector2(230,290), context="browse")`，内部 `CardVisual.new()` + `visual.configure(button, card, dimensions, heading_font, context)`，compare/preview 上下文禁焦点与手型光标。
- **角色格舞台**：新增 [battle_flair.gd](ui/battle_flair.gd)：24 段竖直暖暗渐变、7 层收束背光锥、落点三层椭圆辉光、四角 L 形金线、顶沿细光、上升浮尘；血条叠受光/压暗/25-50-75% 刻度/低血脉冲。角色格边框由灰白改暖金半透明，避免"黑盒子贴灰框"。
- **意图条**：23px 矢量图标按关键词绘制（剑 / 盾 / 上箭头 / 毒滴 / 菱形），替换原 ▸ ◇ 前缀，图标后接文字。首版放大后形似注射器，重画为干净剑形。
- **命中特效**：`CombatEffects._attack()` 重写为 蓄力光球 → 三层拖尾 → 三叠月牙弧 + 白刃 → 双冲击环 → 9 条锥形火花 → 尘团。飘字/图标沿用 `play_status(at, text, tint)`（duration 0.78）与 `play_death(at)`（0.68），浮字 21px（shield/status）/36px（伤害）带描边与弹入缩放；图标资源在 `assets/art/ui/playfeel/`，命中图标 22px、其余 18px。

## 两个观感修正（有明确前后值）

1. **受击闪白过曝**：原 `_apply_flash` 用 `base_color.lerp(_flash_tint, _flash * 0.88)` 且 `emission_energy_multiplier = base + _flash * 3.5`，整个人烧成纯白剪影；下调到 `0.62` 与 `+1.4` 后保留轮廓与材质明暗。
2. **飘字图标写死数字**：图标里硬编码的"12"重绘为无数字徽记，数值完全交给文字动态绘制。

## 屏幕震动与可访问性

- `ui` 战斗层 `_pulse_impact(power, hurt_player)`：先判 `game.profile.settings.get("reduced_motion", false)` 直接 return；全屏 `impact_flash` ColorRect 用 0.03s 起亮 + 0.14s 淡出（受伤红 0.62/0.16/0.12、击敌暖白 0.95/0.86/0.7），背景 punch 缩放 `1.0 + 0.016 * power` 0.04s 进 / 0.14s 回。
- `ActorView` 命中时叠 X 轴震颤顿挫：`shake_w = 0.016 * height * punch`，四段 0.02/0.025/0.025/0.03（除以 speed）后归位，再 `_flash_once(tint, duration)`。护盾命中走独立的 `_animate_shield_hit()` 三阶段（格挡压缩 → 反震 → 复位），冰蓝 tint。

- 长跑 Godot headless 测试/截图用后台 job，避免前台超时。
