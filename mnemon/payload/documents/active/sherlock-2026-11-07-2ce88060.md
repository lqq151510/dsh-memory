# sherlock 用户名枚举：对照组核验方法与站点可靠性实测

时间：2026-11-07。对象：sherlock v0.16.2（仓库 Documents/python/sherlock，入口 ~/.local/bin/sherlock）。本文只记录「结果怎么核验、哪些站点可信」，不重复安装与升级步骤。

## 一、核心结论

- sherlock 输出的 `[+]` 含义是「该站点没有明确拒绝这次请求」，**不是**「该用户名在该站存在」。
- 每个站点只发一次请求，判定完全依赖站点规则文件（`sherlock_project/resources/data.json`）里的状态码/关键词；站点改版、加 CDN、上反爬之后判据立即漂移。
- 实测一批 55 条命中：经对照组复核只有 5 条是真账号；13 条是「任何名字都返回 200」的回声站，10 条明确不存在，22 条被反爬拦截无法机器判定，4 条是本机 SSL 失败。
- 结论：结果只能当候选线索，必须逐条人工确认；不能拿它当「某人注册了哪些站」的证据。

## 二、核验方法：对照组

1. 选一个绝不可能存在的用户名（本次用 `zzqzzq91827364`，足够长且不撞名）。
2. 用**完全相同**的站点列表与参数再跑一次，把两次的 HTTP status、响应长度、页面 title、关键标记词放进同一张表对比。
3. 判读规则：
   - 真号 404 / 假号 200 → 站点在区分真假，`[+]` 有效。
   - 真号与假号都 200 且响应长度接近 → 回声站，`[+]` 信息量为 0。
   - 两边都 403/419/429 或 `Just a moment...` → 机器无法判定，只能人工点开。
   - 两边都 SSLError / ConnectionError → 本机网络或证书问题，**不等于**账号不存在。
4. 只看 `exists` 字段不够：实测 Reddit 返回 403，CSV 里仍写 `Claimed`。必须把 `http_status` 一起读。
5. 有效信号长什么样：假号 404、真号 200 且 title 含用户名（如 `liuyongze · GitHub`）；或站点提供公开 API（Docker Hub API、GitHub API、Mojang API）可直接查。

## 三、站点行为证据（2026-11-07 实测）

### 回声站（真号假号都 200，结果无效）
Telegram、GeeksforGeeks、Codolio、Velomania、Spotify、Instapaper、Hubski、Splice、Odysee、authorSTREAM、opennet、Championat、Archive.org。
典型：Telegram 对任何名字都渲染 `Telegram: Contact @xxx`；GeeksforGeeks 对任何名字都渲染标题 `undefined | GeeksforGeeks Profile` 的壳页。

### 能正确区分（假号 404 或页面明写不存在）
GitHub、Snapchat、Docker Hub（API）、Xbox Gamertag、Hashnode、Dribbble、Rarible、ReverbNation、Vero、YandexMusic、dailykos、interpals、mercadolivre、Chatujme.cz。

### 反爬拦截（需人工打开）
Reddit（403）、HackerNews（419）、Cloudflare 挑战页（Chess、Trakt、Realmeye 等）、DDoS-Guard（AniWorld）、Linktree（406）、threads（429）、Scribd / SlideShare（`Client Challenge`）、Apple Developer（`Security Verification`）。

### 本机网络错误（非「不存在」）
Gumroad、Minecraft（api.mojang.com）、Naver（blog.naver.com）、Shelf —— 均为 SSLError，与本机网络/代理/证书有关。

## 四、使用侧要点

- `--site` 后的站点名必须与 `data.json` 里的键完全一致；带空格的（如 `Docker Hub`）要加引号。
- 默认站点表 481 个，20 路并发、单站默认 60 秒超时；日常用 `--site` 收敛范围，别全站扫。
- 站点表不含 B站、知乎、微博等国内平台。
- CSV 7 列：`username,name,url_main,url_user,exists,http_status,response_time_s`。
- 排查单站误判：`--dump-response` 看原始响应，`--verbose` 看调试信息。

## 五、边界

- 以上站点行为是 2026-11-07 的快照，站点随时会变；每次重要核验都应重跑对照组，而不是直接沿用这张表。
- 只用于查自己或已获授权的账号；对真人做画像属于越界。
