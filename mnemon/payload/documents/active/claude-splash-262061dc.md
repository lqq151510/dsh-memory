## 一、远程攻击「拉开距离」：根因是时序，不是坐标

**根因**：激光原本在命中拍**前 0.15 拍**发射，而那几拍两人正贴脸冲刺，于是看起来像近距离对射。

**最小修复**：把开火点从「命中前」改成「后撤到位后」。

- `makeDuelPlan()` 新增 `shotFar`，记录每次冲撞「后撤到位」的那一拍，汇总成 `plan.far`
- 激光延迟改用 `far`（原为 `b - 0.15`）；蓝色那束再晚 0.035 拍，避免两束同时起亮
- 站位整体外扩：

| 动作 | 改前 (vmin) | 改后 (vmin) |
|---|---|---|
| 冲锋起步 | 23–29 | 28–33 |
| 后撤落点 | 23–31 | 29–34 |
| 瞬移悬停 | 17–23 | 21–27 |
| 镜像穿越 | 21–30 | 27–33 |

- 光束长度 34 → **60vmin（±30）**，枪口光球与落点光斑随之平移

**效果**（3 次挂载抽样、插值真实关键帧）：开火瞬间两人间距由约 13–18vmin（贴脸）变为 **56–64vmin**（半个屏），且光束两端都压在身体上而不是落在空处。

## 二、减少「崩坏」：末日层不能压在螃蟹身上

1. **绘制层级**：裂纹 / 裂口 / 撕裂带挪到 `stage` **之前**，画在角色与字标底下，不再横穿螃蟹
2. **数量减半**：裂纹与撕裂带改为隔一次撞击才裂一次
3. **粒子减量**：落石 18→11、灰烬 22→15、烟 7→5、碎屑 26→20
4. **红雾推迟**：`.csp-doom` 由 0.55 拍推到 **2.0 拍**（拳脚打完后才起），时长压到 1.55 拍，峰值 opacity 1.0→0.95；烟 / 石 / 灰统一推到 2.06 拍之后 → 打斗过程保持干净，末日是「打完才来」
5. **新增 `.csp-shield`**：螃蟹身上一圈暖色护体光，2.06 拍亮起后持续缓慢呼吸；整屏转暗时 Claude 一侧始终有亮区

实拍对比（4600ms / 8400ms 帧）：鲸鱼沉在暗色废墟里，螃蟹外裹暖光仍清晰可辨。

## 四、两个踩坑

1. **预览工具把 SVG 画不出来**：序列化时写成了小写 `viewbox` 而不是 `viewBox`，导致精灵整体不渲染；改用 `createElementNS` 并保留正确属性名后才拿到真实像素。之前「看不清吉祥物」一半原因在这里。
2. **ESM 缓存参数会炸**：`import('/path/client.js?r=01793370637732')` 报 `ERR_MODULE_NOT_FOUND`（Node 把 `?r=` 当成文件名的一部分）。需要缓存失效时改用不同文件名或 `?v=` 之外的策略时先实测。
